# AI 마을

Claude 서브에이전트 일곱 명이 사는 마을입니다.

주민은 **진짜 서브에이전트**라서 실제 개발 업무를 처리하고, 마을 자체는 **규칙 기반 엔진**이라서 API 키 없이 돌아갑니다. 두 층이 분리되어 있어 어느 쪽이든 따로 쓸 수 있습니다.

```
.claude/agents/   주민 — Claude 서브에이전트 7명
village/          세계 — 시계 · 자원 원장 · 마을 일지 (규칙 기반, LLM 호출 없음)
```

## 주민 명부

| 주민 | 서브에이전트 | 맡은 일 |
|---|---|---|
| 촌장 | `mayor-chonjang` | 요구사항을 쪼개 계획을 세우고 누구에게 맡길지 정한다 |
| 농부 | `farmer-nongbu` | 기능 구현 — 밭을 갈듯 코드를 기른다 |
| 상인 | `merchant-sangin` | 의존성 판단 — 사올 것과 만들 것을 저울질한다 |
| 기록자 | `scribe-girokja` | 문서와 일지 — 마을의 기억 |
| 대장장이 | `smith-daejangjang` | 리팩터링과 도구 정비 |
| 의사 | `doctor-uisa` | 버그 진단과 치료 — 증상이 아니라 병인을 찾는다 |
| 경비 | `guard-gyeongbi` | 보안과 코드 리뷰 — 성문으로 뭐가 들어오는지 본다 |

앞의 넷이 **1군**(마을이 돌아가는 최소 구성), 뒤의 셋이 **2군**입니다.

## 주민에게 일 시키기

Claude Code에서 그냥 말하면 됩니다. 각 에이전트의 `description`을 보고 알아서 배정됩니다.

```
이 기능 어떻게 진행할지 계획 좀 세워줘        → 촌장
사용자 검색 API 만들어줘                      → 농부
테스트가 자꾸 깨지는데 원인 좀 찾아줘          → 의사
커밋하기 전에 변경분 한 번만 봐줘              → 경비
```

특정 주민을 콕 집어 부를 수도 있습니다: *"경비한테 이 diff 좀 보라고 해"*

## 마을 돌려보기

```bash
node village/village.mjs init --extended   # 마을을 세운다 (7명 전원)
node village/village.mjs tick 7            # 일주일을 산다
node village/village.mjs status            # 곳간과 주민 상태
node village/village.mjs chronicle         # 기록자가 남긴 일지
node village/village.mjs roster            # 명부 전체
```

```

분위기  ██████████████······ 68

곳간
  식량     22
  목재     13

주민
  촌장    활력 ████████··  82  — 분쟁 조정
  농부    활력 ████████··  75  — 수확
```

주요 명령:

| 명령 | 하는 일 |
|---|---|
| `init [--extended] [--seed N] [--name 이름]` | 마을을 세운다. `--extended`면 7명, 아니면 1군 4명 |
| `tick [일수]` | 하루(혹은 여러 날)를 진행한다 |
| `status` | 날짜 · 분위기 · 곳간 · 주민 활력 |
| `chronicle [--last N]` | 마을 일지 |
| `welcome <주민id>` | 2군 주민을 나중에 들인다 (예: `welcome uisa`) |

## 마을이 돌아가는 규칙

하루(`tick`)마다 이 순서로 일어납니다.

1. **주민이 오늘 할 일을 정한다** — 활력이 30 미만이면 무조건 휴식. 곳간이 인원수보다 비면 촌장을 뺀 전원이 밭으로. 그 외에는 제 일을 한다.
2. **일한 만큼 곳간이 찬다** — 수확량은 계절(가을 ×1.5, 겨울 ×0.5)과 마을 분위기에 좌우된다.
3. **먹는다** — 주민 1명당 식량 1. 모자라면 분위기와 활력이 함께 깎인다.
4. **사건** — 10% 확률로 풍년 · 가뭄 · 역병 · 이방인 · 축제 중 하나.
5. **날이 밝는다** — 10일마다 계절이 바뀐다.

같은 `--seed`면 마을은 **항상 똑같이 흘러갑니다**. "3일차에 무슨 일이 있었나"를 몇 번이고 재현할 수 있습니다.

## 두뇌를 Claude로 바꾸기

주민의 판단은 `village/brains/` 뒤에 숨어 있습니다. 계약은 함수 하나뿐입니다.

```js
decide(resident, world) -> { task, reason, say }
```

지금은 `rule-brain.mjs`(규칙 기반)만 있습니다. Claude API 두뇌를 붙이려면 같은 모양의 모듈을 만들어 `village/brains/index.mjs`의 `BRAINS`에 등록하면 됩니다. 마을 코드는 한 줄도 바뀌지 않습니다.

```bash
VILLAGE_BRAIN=claude node village/village.mjs tick 7
```
