## 요약 (2026-09-02 기준)

- 청주 소재 공유창고 **12곳** (흥덕구 8 · 서원구 2 · 청원구 1 + 참고 1)
- 이 중 **요금을 공개하는 곳은 3곳(알파박스 2, 아이엠박스 1)뿐** — 나머지 8곳은 전화 견적 필요
- 공시 단가 밴드: **월 77,000원(0.4평) ~ 410,000원(아이엠박스 OS 정상가)**
- 평당 월단가: **80,488원(4.1평) ~ 192,500원(0.4평)** — 대형일수록 최대 58% 저렴
- 대전 동일 브랜드 대비 **평균 약 15% 저렴**
- 일반 상온 물류창고(평당 월 3.2~3.3만원)의 2.5~6배 → **10평 이상 상시 보관이면 일반 창고 임대가 유리**

> ⚠️ 네이버 플레이스 전용 등록 로컬 업체가 많아, 구글 기반 웹 검색만으로는 절반 이상이 누락됩니다. 네이버 지도 검색이 1차 소스입니다.
