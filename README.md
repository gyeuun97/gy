## 요약 (2026-09-02 기준)

- 청주 공유창고 브랜드 지점: **3곳** — 알파박스 청주서원점, 알파박스 청주흥덕점, 미니창고 다락 청주향정동점
- 공시 단가 밴드: **월 77,000원(0.4평) ~ 330,000원(4.1평)**, VAT 포함 / 1개월 단위 계약
- 평당 월단가: **80,488원(4.1평) ~ 192,500원(0.4평)** — 대형일수록 최대 58% 저렴
- 대전 동일 브랜드 대비 **평균 약 15% 저렴**
- 다락 청주향정동점은 요금 미공개 → 별도 견적 필요

모든 단가는 공식 홈페이지 공시 기준이며, 계약 전 지점 직접 확인이 필요합니다.
