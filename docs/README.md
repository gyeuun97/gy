# 사업계획서

`사업계획서_탑연리_셀프스토리지.docx` — 소상공인 정책자금(성장기반자금·시설) 신청용 초안.

재생성: `cd docs && npm install docx && node build_bizplan.js`

## 작성 기준
- 부지: 청주시 흥덕구 강내면 탑연리 263-3, 263-4 / 2층 70평 / 자가 건물
- 대표자: 1966년생 여성 개인사업자 (신규 창업)
- 배치: [`models/floorplan.py`](../models/floorplan.py) — 유닛 110개, 만실 879만원
- 재무: [`models/bizplan_finance.py`](../models/bizplan_finance.py) — 5개년 손익·DSCR·BEP

## 정책자금 창구에 관한 판단
요청은 중진공(중소벤처기업진흥공단)이었으나 계획서는 **소진공(소상공인시장진흥공단) 성장기반자금**을 기준으로 작성했다.

| 구분 | 근거 |
|---|---|
| 중진공 원칙 제외 | 상시근로자 5인 미만 소상공인은 중진공 정책자금 대상에서 원칙 제외, 소진공 이용 안내 (2026 융자계획 공고) |
| 청년전용창업자금 불가 | 만 39세 이하 한정 (연 2.5% 고정, 1억). 1966년생 해당 없음 |
| 소진공 성장기반자금 적합 | 시설자금 5억 한도, 8년(거치 3년), 직접대출. 시설투자 9,100만원 조달에 맞음 |
| 우대 | 비수도권 −0.2%p, 여성 −0.3%p(포용금융) 모두 해당 |

## 업종 등록 — 가장 중요한 실무 사항
소진공 지원제외 업종표에서 **비주거용건물임대업(68112)은 "공유오피스·공유주방"만 예외 허용**. 공유창고는 명시되어 있지 않다.
→ 사업자등록 시 **업태 "운수 및 창고업" / 종목 "일반창고업"(KSIC 52101)** 으로 등록해야 정책자금 신청이 가능하다. 부동산임대업으로 등록하면 막힌다.

## 미확정 사항 (신청 전 확인)
- 국세청 6자리 업종코드 — 세무서에서 창고업 코드 확인
- 2026년 소진공 기준금리 정확한 수치 (조사 시점 약 2.96%, 변동)
- 중진공 소상공인 예외 조항의 정확한 문구 — 공고 PDF 원문 확인 (본 조사에서 PDF 접근 실패)
- 2층 화물 승강기 유무, 건축물대장 용도, 소방 요건
