# 국내 로컬 업체 가격 조사 — Claude Code 웹 조사 방법론

청주 공유창고 조사 과정에서 확립한, **국내 로컬 업체 정보를 Claude Code로 수집하는 방법**입니다.

---

## 1. 문제: 기본 WebSearch로는 국내 로컬을 못 본다

Claude Code의 `WebSearch`는 구글 기반 + US 로케일입니다. 그 결과:

| 증상 | 실제 사례 |
|---|---|
| 네이버 플레이스 전용 등록 업체 누락 | 청주 공유창고 16곳 중 **13곳 누락** (3곳만 검색됨) |
| 위키백과·영문 관광정보로 결과가 채워짐 | "청주 셀프스토리지" 검색 시 상위에 Cheongju National Museum, North Chungcheong Province |
| 로컬 업체 주소·전화번호 확보 불가 | 상호만 알고 연락처를 못 얻음 |

`WebFetch`도 한계가 있습니다. SPA(네이버 지도, 다락)는 빈 껍데기를 반환하고, 일부 사이트는 429/403을 냅니다.

**결론: 국내 로컬 조사는 Bash + curl로 직접 수집해야 합니다.**

---

## 2. 검증된 수집 경로

실제로 테스트해서 **되는 것과 안 되는 것**을 구분했습니다.

| 경로 | 결과 | 비고 |
|---|---|---|
| `m.search.naver.com/search.naver?query=` | ✅ **동작** | HTML에 `__APOLLO_STATE__` JSON으로 업체 DB가 통째로 들어있음 |
| `m.search.naver.com/...?ssc=tab.m_blog.all` | ✅ **동작** | 블로그 검색. 요금 미공개 업체의 공식 블로그 발굴 |
| `m.place.naver.com/place/{id}/home` | ✅ **동작** | 업체 공식 홈페이지·블로그 링크 확보 |
| 브랜드 사이트 ID 순회 (`store_N`, `office_idx=N`) | ✅ **동작** | 검색에 안 걸리는 지점까지 전수 수집 |
| `map.naver.com/p/api/search/allSearch` | ❌ **차단** | 데이터센터 IP에 ncaptcha 반환 |
| 다락(dalock.kr) 지점 페이지 | ❌ **가격 없음** | 요금이 앱 전용, 서버 HTML에 미포함 |
| 네이버 블로그 요금표 이미지 | ❌ **추출 불가** | 국내 블로그는 가격을 이미지로 올리는 관행 |

### 2-1. 핵심: `__APOLLO_STATE__` 파싱

네이버 모바일 검색 결과 HTML에는 아래 형태의 JSON이 심어져 있습니다.

```
"PlaceListBusinessesItem:1295506364": {
  "normalizedName": "박스호텔공유창고",
  "category": "보관,저장",
  "fullAddress": "충청북도 청주시 흥덕구 서부로 911-2",
  "virtualPhone": "0507-1468-0844",
  "x": "127.4067558", "y": "36.6010213"
}
```

상호·카테고리·도로명주소·전화번호·좌표가 전부 들어있어, **한 번의 curl로 지도 앱과 동일한 데이터**를 얻습니다.

### 2-2. 검색어 다각화가 필수

쿼리 1개당 5건만 반환되므로, 동의어·행정구역을 조합해 훑어야 전수가 나옵니다.

```
공유창고 / 셀프스토리지 / 무인창고 / 미니창고 / 개인창고 /
짐보관 / 이삿짐보관 / 물품보관창고 / 컨테이너 창고 / 보관창고
× 청주 / 흥덕구 / 서원구 / 청원구 / 상당구 / 오창 / 오송
```

청주 조사에서는 18개 쿼리로 32건을 수집했고, 이 중 청주 소재 유효 업체가 16곳이었습니다.

### 2-3. 브랜드 사이트 ID 순회

프랜차이즈는 지점 페이지가 연속 정수 ID로 노출되는 경우가 많습니다.

- `alphabox.co.kr/store_1` ~ `store_40`
- `iambox.co.kr/sub/selfStorage/storage_view.php?office_idx=1` ~ `520`

이 방식은 **요금표를 원문 그대로** 가져오므로 정확도가 가장 높습니다. 알파박스 청주 2개 지점의 규격·치수·요금·보증금 8행을 이 방법으로 확정했습니다.

## 3. 도구

| 스크립트 | 역할 |
|---|---|
| [`tools/naver_place_search.py`](../tools/naver_place_search.py) | 네이버 플레이스에서 업체 상호·주소·전화 전수 수집 → CSV |
| [`tools/storage_price_crawl.py`](../tools/storage_price_crawl.py) | 브랜드 사이트 지점 ID 순회 → 규격별 요금표 CSV |
| [`tools/naver_blog_price.py`](../tools/naver_blog_price.py) | 네이버 블로그 본문에서 요금 언급 문맥 추출 |

```bash
# 1단계 — 업체 전수 리스트업
python3 tools/naver_place_search.py --csv data/places.csv \
  "청주 공유창고" "청주 셀프스토리지" "청주 무인창고" "오창 공유창고"

# 2단계 — 브랜드 공식 요금표 (1차 출처)
python3 tools/storage_price_crawl.py alphabox --max 40 --filter 청주 --csv data/ab.csv

# 3단계 — 요금 미공개 업체는 블로그에서 단서 확보
python3 tools/naver_blog_price.py --posts 6 --must 옐로박스,청주 "옐로박스 청주 이용요금"
```

## 4. 출처 신뢰도 등급

수집 경로에 따라 데이터의 신뢰도가 다릅니다. **섞어서 쓰면 안 됩니다.**

| 등급 | 출처 | 처리 |
|---|---|---|
| **A** | 업체 공식 홈페이지 요금표 | 그대로 확정 |
| **B** | 업체 공식 블로그(운영자 계정) 요금 안내 | 확정하되 게시일 확인 필수 |
| **C** | 제3자 이용후기 블로그 | 참고만. 프로모션가·타지점 가격일 수 있음 |
| **D** | 검색 요약문 | 근거로 쓰지 않음 |

청주 조사에서 옐로박스는 **B등급**(공식 블로그 `yellobox-official`)으로 확정했고, 캐리박스 강동점 후기에서 나온 숫자는 **C등급**이라 청주 단가로 쓰지 않았습니다.

## 5. 온라인으로 안 되는 것

- **다락**: 요금이 앱 전용. 서버 HTML에 없음 → 앱 또는 1661-0180
- **국내 블로그 요금표**: 대부분 이미지. 텍스트 추출 불가
- **신규 오픈 지점**: 브랜드 사이트 반영 전이면 ID 순회로도 안 잡힘 (예: 아이엠박스 충북대점)

이 셋은 **전화 확인 외에 방법이 없습니다.** 조사 결과에 "미공개"로 남기고 전화 스크립트를 붙이는 것이 정확합니다.

---

## 6. 주의사항

- 요청 간격을 두고, 병렬은 20개 이하로 제한합니다(청주 조사 기준 문제 없었음).
- 수집 대상은 **업체가 공개한 영업 정보**(상호·주소·요금)로 한정합니다.
- 가격은 시점 의존적입니다. 반드시 **조사일을 데이터에 남기고**, 프로모션가는 정상가와 함께 기록합니다.
